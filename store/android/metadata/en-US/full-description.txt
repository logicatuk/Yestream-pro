Full Description:
Yestream is a cross-platform IPTV player that brings all your playlists together in one beautiful app.

📺 LIVE TV & EPG
- M3U/M3U8 playlist support (URL, file, text paste)
- Xtream Codes API integration (live, VOD, series, catch-up)
- Stalker/Ministra portal support
- Full EPG guide with 7-day schedule, reminders, now/next overlay
- Channel groups, favorites, recent channels, search

🎬 MOVIES & SERIES
- Xtream VOD catalog with categories, search, actors
- Series with season/episode browser, watch progress
- TMDB metadata enrichment (posters, ratings, trailers)
- "Up Next" rail for seamless binge-watching

☁️ CLOUD SYNC & MULTI-DEVICE
- Free 7-day trial per device (MAC + 6-digit key)
- Activate via QR code on yestream.ai.studio
- Playlists, favorites, watch progress sync across devices
- Reseller-managed playlists (read-only, locked)

🎯 PLAYBACK ENGINE
- Embedded MPV (hardware decoding, HDR, high-quality scaling)
- HTML5/HLS/Shaka fallback
- External player support (VLC, MPV, IINA)
- Download for offline viewing

⌨️ REMOTE & ACCESSIBILITY
- Web remote control (phone as remote)
- Android TV / Fire TV / LG / Samsung / Apple TV native apps
- Full keyboard, gamepad, remote support
- Parental lock (PIN)

🌍 20 LANGUAGES
English, French, Spanish, German, Arabic, Italian, Portuguese, Russian, Turkish, Japanese, Korean, Chinese (Simplified/Traditional), Dutch, Polish, Greek, Hungarian, Ukrainian, Belarussian, Moroccan Arabic.

🔒 PRIVACY FIRST
- No account required for local playback
- Device identity derived from hardware (no tracking)
- Playlists stored locally unless you enable cloud sync
- Open-source core (MIT), premium cloud features optional
